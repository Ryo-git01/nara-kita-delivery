# 奈良北コース 配送先メモアプリ

登録データ：103件

## 起動方法
1. このフォルダ内の `index.html` をブラウザで開きます。
2. 住所検索欄に住所の一部を入力します。
3. 表示された候補をタップすると配送メモが表示されます。

## 配送先データを更新する方法
- `delivery-data.js` だけを編集します。
- 各データは `address`（住所）、`name`（会社名・場所名）、`memo`（配送メモ）の3項目です。
- `name` がない配送先は空文字 `""` にします。
- 全件を差し替える場合は、`const deliveryData = [...]` の配列部分を新しい配列に置き換えます。
- `index.html` と `app.js` と `style.css` は通常変更不要です。

## 注意
- ローカルストレージやサーバーは使いません。データは `delivery-data.js` に固定で入っています。
- 配送先情報には鍵や入館情報などの機微な運用情報が含まれる場合があります。フォルダやファイルを共有・公開する際は十分注意してください。
- ブラウザで古い表示が残る場合は、ページを再読み込みしてください。
- このアプリは住所文字列を部分一致で検索します。候補は住所の読み順ではなく、ブラウザの日本語文字列比較による並び順で最大5件表示します。

配送先メモアプリ v2

【ファイル】
- index.html：画面構造
- style.css：デザイン
- app.js：検索、取り込み、重複確認、端末内保存

【使い方】
1. ZIPを展開します。
2. index.html をブラウザで開くと動作確認できます。
3. 公開する場合は、index.html / style.css / app.js の3ファイルをGitHubリポジトリの直下にアップロードします。
4. GitHub Pagesで公開したURLをiPhoneのSafariで開き、「共有」→「ホーム画面に追加」でアプリのように使えます。
5. 「＋ データ取り込み」からデータを貼り付け、内容を確認し、次画面で新規追加・更新・取り込まないを選択して保存します。

【重要：配送先データの扱い】
- このZIPには実際の配送先データを含めていません。
- 登録したデータは、そのブラウザの localStorage に保存されます。サーバーには送信しません。
- 同じURLを使っても、端末・ブラウザごとにデータは別々です。自動同期はしません。
- ブラウザのデータ消去、端末の故障、プライベートブラウズなどでデータが失われる可能性があります。大切なデータの唯一の保存先にしないでください。
- 会社名、住所、入退場方法、鍵・ロック情報などを含む実データを、公開リポジトリへアップロードしないでください。公開URLではアプリ本体自体は誰でも開ける場合があります。

【取り込みデータ形式】
各配送先を以下の3項目で記述します。順番は「名前 → 住所 → メモ」です。

名前：〇〇物流センター
住所：大阪府〇〇市〇〇町1-2-3
メモ：北側の入口から入る。納品前に担当者へ連絡。

名前：△△商事
住所：大阪府〇〇市〇〇町4-5-6
メモ：建物の裏側に荷下ろし場所あり。

- 配送先レコードの間は空行を1行入れます。
- 「名前：」という文字列の出現だけでレコードを分割しません。メモに「名前：」が含まれても、空行がなければ同じレコードです。
- 名前・住所・メモは必須です。メモがない場合は「メモ：メモなし」としてください。
- メモは複数行でも構いません。レコード間の空行が区切りになります。
- プレビューでは取り込み対象件数とエラー件数を表示し、配送先一覧は表示しません。エラーがある場合は理由を表示します。
- 名前または住所のどちらかが既存データと一致した場合、確認画面を出します。名前と住所の両方が一致した場合も自動更新しません。
- 保存操作を確定するまでは既存データを変更しません。
